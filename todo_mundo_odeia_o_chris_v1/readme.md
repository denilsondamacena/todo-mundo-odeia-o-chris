## Descrição do projeto

Este projeto consiste em um site enciclopédico e interativo sobre o universo da série "Todo Mundo Odeia o Chris". Foi desenvolvido para a disciplina de Aplicações para Internet, ministrada pelo professor Paulo Henrique Mendes Carvalho, na Universidade Cidade de São Paulo (UNICID), em 2024.

---

## Funcionalidades

* **Navegação estruturada por abas:** Menu interativo superior para trânsito limpo entre a página inicial, personagens, temporadas e contato.
* **Catálogo de Elenco:** Listagem ordenada separando personagens principais, secundários e participações especiais, acompanhada de mini biografias individuais.
* **Guia de Temporadas:** Resumo descritivo das 4 temporadas com número de episódios, canais de transmissão e links diretos para plataformas de *streaming* oficiais.
* **Integração Multimídia:** Player de vídeo incorporado via `iframe` da plataforma Dailymotion e bloco de citação do TikTok.
* **Formulário de Contato Comercial:** Seção contendo inputs validados (`required`), campos de máscara telefônica e geolocalização por mapa embarcado.
* **Glossário Técnico integrado:** Uma seção exclusiva detalhando o uso e a documentação de tags e atributos HTML/CSS avançados que foram aplicados no projeto.

## Como executar o projeto
### Pré-requisitos
Por ser uma aplicação puramente front-end estática (client-side), são necessários apenas:

* Um navegador web moderno e conexão com a internet.

### Passo a Passo
<ol><li>Baixe ou clone os arquivos deste repositório.</li>

<li>Certifique-se de manter os arquivos HTML e a pasta <code>img/</code> dentro do mesmo diretório.</li>

<li>Dê um duplo clique no arquivo <code>index.html</code> para abrir e navegar pelo portal.</li></ol>
